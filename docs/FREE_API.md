# 무료 API 선택 검토

앱은 키 없이 로컬에서 동작합니다. API 설정은 선택 사항입니다.
무료 API가 로컬 모델보다 더 정확하다고 검증된 것은 아닙니다.

1. OpenRouter 계정에서 키를 발급합니다. 키를 채팅·이슈·Git에 붙이지 마세요.
2. 앱의 **무료 API 설정**에서 키를 입력합니다. Windows 자격 증명 관리자에 저장됩니다.
3. 현재 입력/출력 0원인 `공급자/모델:free` 모델을 선택하고 전송 범위를 확인합니다.
4. **혼합** 교정 방식을 선택한 새 작업만 외부 검토를 사용합니다.

전송하는 데이터는 선택한 문제 문단의 원문·번역·짧은 앞뒤 문맥입니다.
PDF 업로드·파일 경로·작업 로그 전송은 없습니다. 제공자 정책은 별도로 확인하세요.
`data_collection: deny` 경로가 없으면 요청을 중단하며, 이것이 모든 제공자의 데이터 처리에 대한 독립적 보증은 아닙니다.

요청 전 현재 모델 목록에서 가격을 확인하고, 입력/출력/요청 가격 상한을 0으로 지정합니다.
유료 모델과 다른 모델/제공자로의 자동 대체를 허용하지 않습니다.
작업당 최대 20개 요청으로 제한하며, 제한/오류/검증 실패 시 기존 로컬 번역을 유지하고 보고서에 표시합니다.
미완료·보류된 검토를 통과나 인간 승인으로 기록하지 않습니다.

2026-10-19에 확인한 OpenRouter 기본 무료 한도는 분당 20회/일 50회이며 계정 조건에 따라 다릅니다.
무료 제공 모델·한도·정책은 바뀔 수 있습니다. 책 전체보다 문제 문단 선택 검토에 적합합니다.
API 키 없이 모의 응답의 가격/라우팅/오류 처리는 검증했지만 실제 API 번역/교정 품질은 측정하지 않았습니다.
