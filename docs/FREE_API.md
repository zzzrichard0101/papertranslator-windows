# 무료 API 선택 검토

앱은 키 없이 로컬에서 동작합니다. API 설정은 선택 사항입니다.
무료 API가 로컬 모델보다 더 정확하다고 검증된 것은 아닙니다.

1. OpenRouter 계정에서 키를 발급합니다. 키를 채팅·이슈·Git에 붙이지 마세요.
2. 앱의 **무료 API 설정**에서 키를 입력합니다. Windows 자격 증명 관리자에 저장됩니다.
3. 현재 입력/출력 0원인 `공급자/모델:free` 모델을 선택하고 전송 범위를 확인합니다.
4. **혼합** 교정 방식을 선택한 새 작업만 외부 검토를 사용합니다.

전송하는 데이터는 선택한 문제 문단의 원문·번역·짧은 앞뒤 문맥입니다.
PDF 업로드·파일 경로·작업 로그 전송은 없습니다. 제공자 정책은 별도로 확인하세요.
`data_collection: deny` 경로가 없으면 요청을 중단하며, 이것이 모든 제공자의 데이터 처리에 대한 독립적 보증은 아닙니다.

요청 전 현재 모델 목록에서 가격을 확인하고, 입력/출력/요청 가격 상한을 0으로 지정합니다.
유료 모델과 다른 모델/제공자로의 자동 대체를 허용하지 않습니다.
작업당 최대 20개 요청으로 제한하며, 제한/오류/검증 실패 시 기존 로컬 번역을 유지하고 보고서에 표시합니다.
미완료·보류된 검토를 통과나 인간 승인으로 기록하지 않습니다.

2026-10-19에 확인한 OpenRouter 기본 무료 한도는 분당 20회/일 50회이며 계정 조건에 따라 다릅니다.
무료 제공 모델·한도·정책은 바뀔 수 있습니다. 책 전체보다 문제 문단 선택 검토에 적합합니다.
API 키 없이 모의 응답의 가격/라우팅/오류 처리는 검증했지만 실제 API 번역/교정 품질은 측정하지 않았습니다.

- [공식 가격·무료 한도](https://openrouter.ai/pricing)
- [공식 제공자·가격 상한 설정](https://openrouter.ai/docs/guides/routing/provider-selection)
- [데이터 정책](https://openrouter.ai/privacy)

대안으로 Groq에도 무료 할당량이 있으나 계정별 한도가 있으며 이 버전에는 별도 연결하지 않았습니다.
Gemini 무료 계층은 콘텐츠의 제품 개선 사용 조건을 확인해야 합니다.

2026-10-20 공식 문서와 공개 모델 목록을 다시 확인했습니다. 아래는 연결/평가 후보이며,
현재 앱의 OpenRouter 키 입력란에 다른 제공자의 키를 넣어 사용할 수는 없습니다.

| 경로 | 현재 확인한 무료 수단 | 적용 후보와 한계 |
| --- | --- | --- |
| Groq Free Plan | Qwen3.8 27B, 표기 한도 30요청/분·1,000요청/일·8,000토큰/분·200,000토큰/일 | 로컬과 작업 분담. 같은 계열 모델이므로 독립 의미 검수 효과는 별도 비교 필요. 정확한 한도는 계정 화면에서 확인 |
| Gemini Free Tier | Gemini 3.8 Flash의 기본 텍스트 입력/출력 무료 | 다른 계열의 의미 검수 후보. 모델·계정별 할당량 확인과 콘텐츠의 제품 개선 사용 조건 동의 필요 |
| OpenRouter :free | 공개 목록에서 Nemotron 3 Super 120B 등 입력/출력 0원 확인 | 현재 연결을 활용할 수 있으나 스키마·비수집 경로 가용성과 실제 한국어 품질은 미검증 |

Groq의 공개 450토큰/초 표기는 제공자 수치이며, 이 앱에서 측정한 속도가 아닙니다.
짧은 응답이 빨라도 분당 토큰 한도 때문에 지속 처리량은 낮아질 수 있습니다.
무료 한도가 소진되면 로컬 처리로 남은 일을 수행하는 방식이 필요하며 유료 업그레이드/대체는 제외합니다.
현재 API 키가 없어 실제 외부 번역 요청은 수행하지 않았습니다.

Cerebras의 현재 제공은 결제 수단 등록이 필요한 30일/$5 체험이며 상시 무료 계층이 없다고 명시되어 있어,
지속적으로 무료인 수단을 찾는 이번 후보에서는 제외했습니다.
