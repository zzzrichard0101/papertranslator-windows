# 개인정보와 로컬 데이터

기본 모드는 로컬 처리입니다. 설치·업데이트용 모델/런타임 다운로드는 인터넷을 사용합니다.
혼합 모드를 명시적으로 선택한 작업은 문제 문단의 원문·번역·짧은 앞뒤 문맥을 OpenRouter와 처리 제공자에게 전송합니다.
PDF 파일·로컬 경로·작업 로그는 전송하지 않습니다. 제공자의 데이터 정책이 적용되므로 비공개 원고에 사용하기 전에 확인하세요.
API 키는 Windows 자격 증명 관리자에 저장하고 설정·작업·품질 JSON에 넣지 않습니다.
무료 모델/0원 상한/비수집 제공자 경로만 요청하며, 조건이 맞지 않거나 무료 한도가 끝나면 로컬 결과를 유지합니다.
OCR도 로컬 CPU에서 처리합니다. 이미지는 메모리에서 인식하며 OCR 원문·점수는 로컬 작업 및 결과 보고서에 남습니다.
OCR 모델은 설치 패키지에 포함되고 작업 중 다운로드하지 않습니다. ONNX Runtime 원격 측정은 비활성화합니다.
로컬 worker는 루프백 주소에 임시 키로 연결하고 외부 DNS/연결을 차단합니다.
혼합 worker는 고정 API 호스트의 공개 DNS 주소와 443 포트만 추가 허용합니다.
이 제한은 Python worker에 적용되며,
네이티브 엔진을 OS 방화벽으로 격리하는 기능은 아닙니다.

로컬 저장 위치:

| 위치 | 내용 |
| --- | --- |
| `%LOCALAPPDATA%\PaperTranslator\models` | 다운로드한 모델·라이선스·검증 정보 |
| `...\runtimes`, `...\downloads` | 추론 런타임·다운로드 파일 |
| `...\jobs` | 원본 사본, 추출 텍스트, 프롬프트, 번역문, 체크포인트, 엔진 로그 |
| `...\settings.json`, `...\model_registry.json` | 저장 폴더·모델 경로·설정 |
| 선택한 저장 폴더의 `Papers` | 원본 복사본, 번역/대조 PDF, 노트, 검토 보고서 |

고급 사용자는 `PAPERTRANSLATOR_HOME` 환경변수로 로컬 데이터 루트를 지정할 수 있습니다.
이 값은 설치·모델 선택·앱 실행에 일관되게 적용하세요.
앱 삭제만으로 문서·작업·모델이 삭제되지는 않습니다. 필요한 작업을 백업하고 앱을 종료한 뒤 직접 정리하세요.

버그 신고에는 증상을 재현하는 **가상의 짧은 문서**를 사용하세요.
원문·출력 PDF·Vault·jobs·로그·실제 경로·인증 정보는 공개 이슈에 올리지 마세요.
문서 안의 지시문은 번역 데이터로 취급합니다. 앱은 문서 지시로 비밀번호나 외부 파일을 읽지 않습니다.

저장소와 공개 아카이브에는 소스, 테스트, 합성 입력, 문서와 의존성 잠금 파일만 포함합니다.
비공개 작업 폴더의 복사본이나 익명화하지 않은 실행 결과는 포함하지 않습니다.
