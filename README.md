# PaperTranslator Windows

영어 텍스트·스캔·혼합 PDF를 한국어로 번역하는 Windows 앱입니다. 로컬 처리가 기본이며 무료 API 검토를 선택할 수 있습니다.
한국어 PDF, 원문과 번역을 나란히 배치한 PDF, Obsidian용 노트와 문단 검토 보고서를 만듭니다.

**공개 알파**입니다. 번역이 생성됐다는 사실은 의미 정확도를 보장하지 않습니다.
친족·시간 관계와 전문용어 오역이 남아 있으므로 원문과 대조하세요.
영어 인쇄체의 로컬 OCR을 지원합니다. 원문 조판 복원은 아직 지원하지 않습니다.

## 요구사항

- Windows 10/11 x64, NVIDIA GPU와 호환되는 드라이버
- 소스 실행 시 Python 3.12 및 [uv](https://docs.astral.sh/uv/getting-started/installation/)
- 첫 설치에는 인터넷과 여유 디스크 공간이 필요합니다. 모델 설치 후 번역은 로컬에서 수행합니다.
- 개발 장비 RTX 4090에서 관측한 GPU 전체 사용량: Hy-MT2 7B 약 9.1GiB, Qwen3.8 27B 약 19.5GiB
- 이 메모리 수치는 화면·다른 앱 사용량을 포함합니다. 다른 GPU에서의 동작은 검증하지 않았습니다.

## 시작하기

저장소를 내려받은 폴더에서 실행합니다. PowerShell 실행 정책을 변경할 필요는 없습니다.
정책이 `.ps1` 실행을 제한하는 환경에서는 아래 Python 명령을 직접 사용하세요.

```powershell
uv sync --frozen --group dev
uv run python scripts/fetch_ocr_models.py
uv run python scripts/bootstrap.py
uv run python scripts/select_model.py hy7b
uv run python -m papertranslator
```

기본 설치는 Hy-MT2 7B와 추론 런타임을 약 6.8GB 다운로드합니다. 크기와 SHA256을 확인합니다.
설치 스크립트는 모델과 런타임을 사용자 AppData에 저장하며 시스템 PATH·드라이버·방화벽을 변경하지 않습니다.

24GB급 GPU에서 더 큰 모델을 사용하려면 약 17GB를 추가로 다운로드합니다.

```powershell
uv run python scripts/fetch_qwen38.py
uv run python scripts/select_model.py qwen38
```

실험 기본값 Qwen3.8은 일부 진단 문단을 7B보다 잘 옮겼지만 모든 입력에서 우수하다는 검증은 없습니다.
앱의 모델 목록에서 경량 모드로 되돌릴 수 있습니다. 이미 시작한 작업은 모델 설정을 고정합니다.
추가 비교 모델 두 개는 `scripts/fetch_candidates.py`로 설치할 수 있습니다(약 36GB 추가).
TranslateGemma에는 별도 Gemma 이용 조건이 적용됩니다. 번역 모델 가중치는 이 저장소와 릴리스에 포함하지 않습니다.

## 사용법

1. PDF를 선택하거나 드롭합니다.
2. 제목·쪽 범위·모델·OCR·결과 저장 폴더를 선택합니다. 쪽 범위 예: `1-12,15,20-`.
3. 번역을 시작합니다. 취소한 작업은 작업 기록에서 이어갈 수 있습니다.
4. 한국어 PDF·영한 대조·문단 검토를 열어 원문과 비교합니다.

결과는 선택한 폴더의 `Papers` 아래 새 폴더에 저장합니다. 같은 제목은 번호를 붙이고 기존 노트를 덮어쓰지 않습니다.
`Original.pdf`는 선택한 원본 전체의 복사본입니다. `Korean.pdf`와 `Bilingual.pdf`는 선택한 쪽의 재배치 출력입니다.
Obsidian Vault를 저장 폴더로 지정하면 노트의 상대 링크를 사용할 수 있습니다.
분야 선택은 문맥과 관련 용어 힌트에도 사용합니다. 검증된 분야별 모델 라우팅은 아닙니다.

교정 방식의 **문맥·용어 정리**는 앞뒤 문단의 짧은 문맥과 용어 힌트를 사용합니다.
짧은 제목·문장은 옆 문단의 내용을 끌어오지 않도록 주변 문맥 없이 번역합니다.
**정밀**은 설치된 번역/보완 모델과 Qwen 교정 모델을 순서대로 실행합니다. Hy-MT2 초벌을 선택하면 Qwen이 원문과 대조해 교정합니다.
다른 모델을 초벌로 선택하면 Hy-MT2 보완 번역도 함께 참고할 수 있습니다. 두 모델이 같은 오역을 할 수도 있습니다.
교정문은 실제 원문/초벌 인용 근거와 숫자·코드·링크 검사를 거쳐 반영하고 초벌/후보/판정을 로컬에 남깁니다.
이는 기계 교정이며 독립 전문가 승인이나 의미 정확도 인증이 아닙니다. 정밀 모드는 추가 시간이 걸립니다.
**혼합**은 정밀 처리 후 문제 문단만 무료 API로 추가 검토합니다. [무료 API 설정](docs/FREE_API.md)을 먼저 확인하세요.

OCR 기본값은 **자동**입니다. 텍스트가 적은 쪽이나 이미지가 포함된 쪽을 로컬 CPU에서 인식하고,
기존 텍스트와 겹치는 결과는 중복을 줄입니다. **끄기**는 PDF 텍스트만 사용하며,
**강제**는 기존 텍스트 대신 모든 쪽을 다시 인식하므로 잘못된 숨은 텍스트 층이 있는 스캔에 사용할 수 있습니다.
스캔의 문장도 연속한 쪽의 문단 연결을 거칩니다. OCR 설정은 작업별로 고정됩니다.
OCR 엔진·소형 인식 모델은 앱에 포함되어 별도 설치나 인터넷 연결이 필요하지 않습니다.
영어 인쇄체에는 Tesseract best LSTM 데이터를 사용하고, 짧은 글자/회전 인식 실패에는 기존 RapidOCR 경로를 사용합니다.
소스 실행은 `uv sync` 후 `scripts/fetch_ocr_models.py`로 고정된 영어 데이터를 설치합니다. OCR은 번역용 VRAM을 사용하지 않습니다.
영어 OCR 경로는 확률 점수를 제공하지 않아 **점수 미제공**으로 기록합니다. 점수가 없다는 사실을 정확하다는 뜻으로 해석하지 않습니다.
OCR 결과는 로컬 작업에 캐시해 같은 원본의 재분석에 재사용합니다. 반복 쪽 머리말은 본문에서 분리합니다.
인식 신뢰도는 원문 판독의 보조 점수이며 정확도 확률이 아닙니다. 낮은 점수는 보고서에 표시합니다.
손글씨·흐린 스캔·수식·복잡한 표/2단·일부 겹친 텍스트의 읽기 순서 및 중복 처리는 한계가 있습니다.
숫자와 인명은 이미지 원문을 확인하세요. OCR이 원본 PDF 자체를 수정하지는 않습니다.

연속 선택한 쪽의 끝과 다음 쪽의 시작이 미완성 문장으로 이어지면 하나의 문단으로 번역합니다.
번역면의 `[연결 문단: 원본 ...쪽]`에 함께 표시하고 다음 쪽에는 번역 위치를 안내합니다.
완결 문장·새 제목·건너뛴 선택 쪽은 연결하지 않습니다. 복잡한 2단/표의 읽기 순서는 검토가 필요합니다.
구버전의 작업을 새 버전으로 재개하면 분석기 버전이 바뀐 작업은 원본에서 다시 분석·번역합니다.
기존 결과 폴더와 사용자 메모는 덮어쓰지 않습니다.
자동 검사에 실패해도 번역 후보가 있으면 PDF와 문단 검토에 **검토용 번역**으로 표시합니다.
해당 문단은 여전히 실패로 집계하며 원문·원시 응답을 보존합니다. 후보가 승인됐다는 뜻은 아닙니다.

남은 번역 시간은 본문 길이와 현재 실행의 처리 속도로 계산한 **대략적인 범위**입니다.
초기에는 속도 측정 중으로 표시하며, 문단이 지연되거나 처리 속도가 지속적으로 바뀌면 재측정합니다.
모델 준비·PDF 분석/OCR·선택적 추가 검수·PDF 생성/저장 시간은 번역 예상에 포함하지 않고 단계로 표시합니다.
재개 시 완료된 번역은 재사용하고 처리 속도는 새 실행에서 다시 측정합니다.

## 개인정보와 로컬 데이터

사용자 문서·번역문·작업 기록·모델 설정은 공개 저장소에 포함하지 않습니다.
번역 결과와 로그는 **사용자의 컴퓨터에는 남습니다**. 로그나 작업 폴더를 그대로 이슈에 첨부하지 마세요.
자세한 위치와 삭제 범위는 [개인정보 안내](docs/PRIVACY.md)를 확인하세요.
무료 API를 명시적으로 선택한 작업만 원문/번역의 선택 문단을 외부로 전송합니다. PDF 업로드와 유료 대체 경로는 없습니다.
