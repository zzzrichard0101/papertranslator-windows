진행 상태: Windows 0.4.0 공개 알파. 인계 명세 전체 완료가 아님.

구현:
- PySide6 UI, 별도 worker, 루프백의 로컬 llama.cpp CUDA 엔진
- 4개 모델 선택과 작업별 모델/프롬프트/품질 모드 스냅샷
- 로컬 기본, 문맥 번역/다중 모델 교정/선택 무료 API 검토/기존 방식
- 번역 전문 Hy-MT2와 Qwen 교정의 순차 실행, 필요 시 보완 번역 비교
- 교정 원문·초안 인용 근거, 숫자·링크·코드 검사 후 후보 채택
- 초안·교정 근거·수정 이력 보존, 자동 교정과 독립 검수·인간 승인 구분
- 짧은 인접 문맥과 분야별 용어 힌트, 반복 쪽 머리말 제거, 쪽 사이 문장 연결
- 공식 영어 LSTM OCR 우선, RapidOCR 보조, 영어 인쇄체·스캔/혼합 PDF 지원
- OCR SHA256 확인/원문·좌표·캐시 보존, 신뢰도 없는 엔진은 점수 없음 명시
- 원본 해시 보존, 물리 쪽 선택, 체크포인트, 취소/재개, 부분 실패 재시도
- 본문 길이/강건한 처리 속도 기반 시간 범위, 측정/지연/속도 변화 재측정 표시
- 한국어 재배치/영한 대조 PDF, 노트, 품질 JSON, 문단 검토 HTML
- 선택 무료 API: Windows 자격 증명 관리자, 고정 API 호스트, 가격 0 검증/상한
- PDF 업로드 없음, 작업당 요청 제한, 유료 대체 금지, 오류 시 로컬 결과 유지
- 일반 worker 외부 DNS/연결 차단, 혼합 worker는 명시된 API 호스트만 예외
- 전역 시스템/드라이버/Python 변경 없음, 앱이 소유한 엔진만 종료

검증과 한계:
- 단위 검사 및 합성 job/체크포인트/내보내기 통합 검사. 정확도 백분율 없음
- 실제 모델의 작은 개발 진단에서 직역·부정·인과·의무 표현 일부 개선
- 경제 문맥의 depression 등 교정 모델도 놓치는 사례가 있어 용어/검사 보완
- 공식 OCR의 일부 인쇄 영어 샘플 줄 복원 개선. 전체 OCR 정답 평가는 없음
- API 키 없음: 모의 HTTP 응답으로 연결 보호/실패 동작 검사, 실서비스 품질 미측정
- API 무료 한도·제공자·정책은 변할 수 있으며 비수집 경로 부재 시 사용 불가
- 자동 검사 0건이나 자동 교정 완료는 의미 정확도 또는 사람의 승인 보증이 아님
- 본문 시간 범위는 휴리스틱. OCR/교정/저장은 별도 단계이며 완료 시각 보증 없음
- 독립 검수 자격은 승인하지 않음. 자동 교정은 별도 기능으로 보고서에 표시
- native 엔진은 OS 방화벽으로 격리하지 않음. 실제 NIC 비활성화 시험 미실시
- 개발 결과는 test_vault에 새로 생성하며 원문/사용자 결과를 덮어쓰지 않음

남은 개발:
1. PDFMathTranslate/BabelDOC 기준선, 원문 조판 복원, 복잡한 표/수식/2단 IR
2. OCR 손글씨/저해상도/다국어와 복잡한 읽기 순서, 전체 문서 OCR 정답 평가
3. 전문가 기준 독립 held-out 평가와 검수 모델 자격 평가
4. 인명/약어/승인 번역 메모리, 검토 화면 편집·되돌리기
5. 다운로드 UI, 대기열, 알림, 장문/휴면/드라이버 장애·sleep/wake 검증
6. 실제 API 키로 제공자별 품질·가용성 검증, 무료 할당량 표시
