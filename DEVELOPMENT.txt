구현:

- 선택 수정 구절 교정: 긴 문단 전체 검토 후 고유 구절만 생성, 전 문단 검사와 전체 교정 복귀, 기본 꺼짐
- 합성 GPU/CPU 비교 도구, 다른 GPU worker와 충돌 거부, 실제 draft/accepted 토큰·기동/추론 시간·출력 차이 계측
- 제목·머리말·열 간격·아래 가로선이 있는 2열 문장형 표의 셀/행 복원과 보수적 2단 읽기 순서
- 유일한 원문 인용으로 대응하는 오류 문장만 선택 재처리, 전체 문단 재검사와 실패 시 전체 재번역 복귀
- 새 작업 처리 버전 2, 기존 버전 0/1 작업의 분석·문맥·체크포인트 식별 유지
- 새 작업의 OCR 누락 후보 영역 재인식(최대 6곳/쪽·25% 면적), 같은 기준선 조각 복원·원문 좌표/출처 보존
- native 코드·도식·식별된 셀 경계 보존, 미확인 Table 캡션 페이지 본문 조각 합치기 제외
- 선정 학술 용어·명시적 약어 정의를 문서 전체에서 공유, 중의 약어/미등록 정의 추측과 초안 용어 학습 금지
- 기존 작업은 처리 버전이 없으면 이전 OCR·문맥·체크포인트 정책 유지
- 문단별 SQLite 트랜잭션 저장, 기존 JSON 가져오기·호환 사본·정확한 입력의 작업 내 응답 재사용
- 기본 순차 처리와 선택 2문단 동시 처리(실험), 동일 요청 문맥 유지·시작 실패 시 순차 재시도
- PySide6 UI, 별도 worker, 루프백의 로컬 llama.cpp CUDA 엔진
- 4개 모델 선택과 작업별 모델/프롬프트/품질 모드 스냅샷
- 로컬 기본, 문맥 번역/다중 모델 교정/선택 무료 API 검토/기존 방식
- 번역 전문 Hy-MT2와 Qwen 교정의 순차 실행, 필요 시 보완 번역 비교
- 교정 원문·초안 인용 근거, 숫자·링크·코드 검사 후 후보 채택
- 초안·교정 근거·수정 이력 보존, 자동 교정과 독립 검수·인간 승인 구분
- 짧은 인접 문맥과 분야별 용어 힌트, 반복 쪽 머리말 제거, 쪽 사이 문장 연결
- 공식 영어 LSTM OCR 우선, RapidOCR 보조, 영어 인쇄체·스캔/혼합 PDF 지원

- 원본 해시 보존, 물리 쪽 선택, 체크포인트, 취소/재개, 부분 실패 재시도

- 기존 번역 문장 단위의 쪽 대응, 경계 문장 양쪽 표시, 대응 추정/미확정 구분

- 좁은 줄바꿈을 재사용하지 않는 전체 항목 보충면, 짧은 목록/행 표지의 배치 보정

- 인식용 이미지의 긴 선 제거, 어두운 쪽 반전 후보 비교와 표 오탐 완화

- 전 출력 쪽의 텍스트·겹침·페이지 이탈 검사, 교정 거부 시 최대 3번 근거 재검사

- 전역 시스템/드라이버/Python 변경 없음, 앱이 소유한 엔진만 종료

검증과 한계:
- 240개 단위 검사, 합성 전체/부분 교정의 최종 번역 일치·범위 유지·잘못된 후보 복귀·원문 픽셀·배치·재개 검사
- 실제 CPU 27B의 부분 교정 성공, 작은 MTP 입력의 예측 3/채택 1 토큰 확인. CPU 실행을 GPU 속도/의미 정확도 보증으로 해석하지 않음
- MTP/부분 출력은 실험 옵션. 확률 샘플링과 실제 장문에서의 동일 품질·속도 비교, 자동 가속 설정 선정은 미완료
- 217개 단위 검사 및 합성 표·2단·부분 재처리 worker/원문 픽셀/배치/재개 통합 검사
- 실제 스캔 1쪽의 원문 단어별 출현 수를 유지하며 2열 표 14셀 식별. OCR 자체의 철자/누락 오류는 별도 문제
- 부분 재처리는 숫자/일부 결정적 오류와 고유 인용 대응이 있는 경우만 적용. 대응이 없으면 기존 전체 재번역
- 부분 재처리 실패는 최대 1회 추가 호출 비용이 있음. 전체 처리 시간·의미 품질 비율은 아직 측정하지 않음
- 206개 단위 검사 및 실제 CPU OCR 누락 복구/배치/원문 면 픽셀/캐시 재개 합성 통합 검사
- 실제 스캔 3쪽에서 원문 단어 수·내용 유지, 번역 대상 36개에서 31개로 감소; 전체 번역 속도·정확도 비율 아님
- 누락 재인식은 글자 모양 후보만 제한적으로 시도하며 손글씨·가림·희미한 글자·복잡한 표 전체 누락을 보증하지 않음
- 자동 용어 공유는 선정 용어와 명시된 정의에 한정. 인명·임의 전문용어 전체의 자동 통일은 미완료
- 단위 검사 및 합성 job/체크포인트/내보내기 통합 검사. 정확도 백분율 없음
- 실제 모델의 작은 개발 진단에서 직역·부정·인과·의무 표현 일부 개선
- 경제 문맥의 depression 등 교정 모델도 놓치는 사례가 있어 용어/검사 보완
- 공식 OCR의 일부 인쇄 영어 샘플 줄 복원 개선. 전체 OCR 정답 평가는 없음
- API 키 없음: 모의 HTTP 응답으로 연결 보호/실패 동작 검사, 실서비스 품질 미측정
- API 무료 한도·제공자·정책은 변할 수 있으며 비수집 경로 부재 시 사용 불가
- 자동 검사 0건이나 자동 교정 완료는 의미 정확도 또는 사람의 승인 보증이 아님
- 본문 시간 범위는 휴리스틱. OCR/교정/저장은 별도 단계이며 완료 시각 보증 없음
- 독립 검수 자격은 승인하지 않음. 자동 교정은 별도 기능으로 보고서에 표시
- native 엔진은 OS 방화벽으로 격리하지 않음. 실제 NIC 비활성화 시험 미실시
- 개발 결과는 test_vault에 새로 생성하며 원문/사용자 결과를 덮어쓰지 않음
